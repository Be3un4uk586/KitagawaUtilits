## 📖 О программе

**KitagawaUtilits** — это настольное приложение для Windows, которое помогает обычному пользователю
ухаживать за Android-смартфоном или планшетом: находить и скачивать прошивки, безопасно убирать
встроенную рекламу, следить за здоровьем батареи и железа, транслировать экран телефона на компьютер
и проверять целостность файлов.

Программа написана так, чтобы ей мог пользоваться даже новичок: крупные кнопки, понятные подсказки,
встроенная пошаговая инструкция и защита от опасных действий. **Для очистки от рекламы Root не нужен**,
а перед прошивкой и очисткой приложение проверяет заряд батареи, чтобы телефон не выключился в самый
неподходящий момент.

### 🧹 Безопасная очистка от рекламы (ADB Debloater без Root)

- Режим **«Только безопасная очистка (Рекомендуется)»** включён по умолчанию.
- Показываются только проверенные рекламные и мусорные пакеты из белого списка — важные системные
  приложения скрыты, поэтому случайно удалить нужное не получится.
- Кнопка **«Вернуть всё как было»** возвращает удалённые приложения обратно.
- Личные файлы, фото и контакты **не затрагиваются**.
- **Root и разблокировка загрузчика не требуются.**

### 🔋 Здоровье и железо

Вкладка **«Здоровье и железо»** через ADB показывает:

- уровень заряда и температуру батареи;
- расчётную ёмкость и количество циклов зарядки;
- модель устройства, процессор, объём ОЗУ;
- состояние загрузчика и базовую информацию о безопасности.

### 📺 Трансляция экрана на ПК (scrcpy)

- Экран телефона открывается в отдельном окне Windows.
- Управление мышкой и клавиатурой — удобно, если сенсор разбит или не работает.
- При первом запуске программа сама скачивает последний `scrcpy-win64` с GitHub
  (≈11 МБ, распаковка ≈30 МБ) в локальную папку данных.

### 🛠 Помощник и APK

- **Установка драйверов** Google USB Driver, если компьютер не видит телефон.
- **Установка `.apk`** с ПК на телефон в один клик.
- **Проверка прошивки по MD5 / SHA256** — сравнение хеша файла с хешем с сайта производителя,
  чтобы не установить битый или подменённый файл.

### 🌐 Пять языков интерфейса

- **Русский**, **English**, **Українська**, **Español** и **中文**.
- Компактный выбор языка `🌐` в нижней части левой боковой панели.
- Весь интерфейс переводится **сразу, без перезапуска программы**: вкладки, заголовки,
  кнопки, статусы подключения, карточки диагностики и форма обратной связи.
- Выбор языка сохраняется в `%LOCALAPPDATA%\KitagawaUtilits\settings.json`.

### 🎨 Интерфейс и удобство

- Мягкое тёмно-графитовое оформление с коралловыми акцентами.
- Анимированная заставка при запуске и фирменная иконка приложения.
- Плавная прокрутка всех вкладок колесиком мыши — нижние кнопки всегда доступны.
- Вкладка **«💬 Поддержка и идеи»**: можно предложить добавить модель или прошивку,
  сообщить об ошибке и попросить улучшение прямо из программы.
- Встроенная вкладка **«📖 Инструкция»** с пошаговыми действиями для новичков.

### 🛡️ Защита от «окирпичивания»

- Перед прошивкой и очисткой проверяется заряд батареи: при низком заряде действие не начнётся.
- Для прошивки рекомендуется заряд **не ниже 50 %**, для очистки — **не ниже 30 %**.
- Перед установкой прошивки можно проверить её хеш и убедиться, что файл целый.

## 🚀 Быстрый старт

### Вариант 1. Готовая сборка (рекомендуется)

1. Откройте раздел **[Releases](../../releases/latest)**.
2. Скачайте `KitagawaUtilits.exe` (или архив `KitagawaUtilits.zip` — в нём уже лежат `adb`, `fastboot`
   и инструкция).
3. Положите файл в отдельную папку, например `C:\KitagawaUtilits`.
4. Запустите `KitagawaUtilits.exe`.
5. Если Windows SmartScreen покажет предупреждение, нажмите **«Подробнее» → «Выполнить всё равно»**
   (файл не подписан цифровой подписью — это нормально для открытых проектов).

> 💡 Папку `tools` с `adb.exe` и `fastboot.exe` нужно держать рядом с `.exe`.
> В релизном архиве она уже есть.

### Запуск из исходников

```bash
git clone https://github.com/Be3un4uk586/KitagawaUtilits.git
cd KitagawaUtilits

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
python main.py
```

> Для работы функций с телефоном положите `adb.exe`, `fastboot.exe`, `AdbWinApi.dll` и
> `AdbWinUsbApi.dll` в папку `tools` рядом с `main.py` (или используйте релизный архив).

## 📱 Подготовка телефона

1. **Включите режим разработчика**
   `Настройки → О телефоне → Номер сборки` — нажмите 7 раз.
2. **Включите отладку по USB**
   `Настройки → Система → Для разработчиков → Отладка по USB`.
3. **Подключите телефон** кабелем к компьютеру.
4. **Разрешите отладку** — на экране телефона поставьте галочку «Всегда разрешать» и нажмите
   «Разрешить».
5. **Проверьте связь** — в левом меню должна загореться зелёная плашка «Телефон подключён»,
   либо откройте вкладку **«🔄 Управление телефоном»** и нажмите «Проверить телефон».

> ⚠️ «Заводская разблокировка» (OEM unlocking) нужна **только** для смены прошивки.
> Для очистки от рекламы и установки APK она не требуется.

## 🛡️ Безопасность

- Приложение **не удаляет личные данные** — только выбранные рекламные и мусорные пакеты.
- Все действия можно **отменить** кнопкой «Вернуть всё как было».
- Опасные операции блокируются при низком заряде батареи.
- Файлы прошивок можно проверить по **MD5 и SHA256** перед установкой.
- Для очистки от рекламы **не нужны Root и разблокированный загрузчик**.

> ❗ На Vivo/iQOO и Huawei/Honor загрузчик заблокирован производителем — для них используйте
> только официальное обновление или сервисный центр.

## 🔧 Сборка .exe

```bash
pip install -r requirements.txt
pyinstaller --noconfirm --clean --onefile --noconsole --icon=app.ico --name KitagawaUtilits --add-data "app.ico;." --add-data "locales.json;." --add-data "tools;tools" --add-data "firmwares.json;." --collect-all customtkinter main.py
```

Готовый файл появится в `dist\KitagawaUtilits.exe`. В режиме `--onefile` внутрь `.exe`
уже упакованы `locales.json`, `firmwares.json`, `app.ico` и папка `tools` с `adb`/`fastboot`.

## ❓ Решение проблем

<details>
<summary><b>Компьютер не видит телефон</b></summary>

1. Проверьте кабель и попробуйте другой USB-порт (лучше на задней панели ПК).
2. Откройте вкладку **«🛠 Помощник и APK»** и нажмите **«Установить драйверы»**.
3. Убедитесь, что включена «Отладка по USB» и на телефоне нажато «Разрешить».
4. Перезапустите программу и нажмите «Проверить телефон».

</details>

<details>
<summary><b>Windows SmartScreen блокирует запуск</b></summary>

Нажмите **«Подробнее» → «Выполнить всё равно»**. Исполняемый файл не подписан сертификатом,
поэтому SmartScreen может показывать предупреждение.

</details>

<details>
<summary><b>Не скачивается scrcpy</b></summary>

Проверьте подключение к интернету и доступ к `api.github.com`. При первом запуске скачивается
около 11 МБ — это может занять немного времени.

</details>

<details>
<summary><b>Хеш прошивки не совпадает</b></summary>

Файл повреждён или скачан не полностью. Скачайте прошивку заново и повторите проверку
MD5/SHA256. Не устанавливайте файл с несовпадающим хешем.

</details>
